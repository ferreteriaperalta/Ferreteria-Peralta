# Ferretería Peralta 🛠️

Sistema de gestión desarrollado en PHP y MySQL para el control de una ferretería.

##  Objetivo del Proyecto
Desarrollar una aplicación que permita administrar clientes, productos, ventas, proveedores y vendedores, aplicando operaciones CRUD y reportes para análisis de información.

##  Funcionalidades
- CRUD de Clientes 
- Lectura de Productos 
- Lectura de Ventas 
- Lectura de Proveedores 
- Lectura de Vendedores 
- Reportes con filtros y consultas SQL 

## 📊 Reportes Incluidos
1. **Reporte 1 – Operadores Condicionales, Lógicos y Orden**
   - Filtrado de ventas por cliente y fecha.

2. **Reporte 2 – Uso de JOIN**
   - Relación entre ventas, clientes y vendedores.

3. **Reporte 3 – Funciones de Agregación**
   - Totales de ventas y análisis de información.
